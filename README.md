# mcpewin10
launcher open source para MC: Windows 10 Edition (Build 0.15.10.0)

## What inside?
- Untethered from Windows Store (You can play even without Microsoft Account and Without Windows Store installed)
- Full Game Unlocked
- All Skins and Capes Unlocked


## Warning
This is clonned version of MC, That means you can install MC Bedrock Edition along MC without data loss
